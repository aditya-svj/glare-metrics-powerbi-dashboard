# 📊 Glare Metrics – Power BI Dashboard
Project Overview

Glare Metrics is an interactive Power BI dashboard designed to analyze business performance using key sales and operational metrics. The dashboard transforms raw data into actionable insights.

🔹 Objective

Monitor revenue and profitability trends

Track KPI performance

Identify high-performing segments

Enable data-driven decision-making

🔹 Tools & Technologies

Power BI

DAX

Power Query

Data Modeling

🔹 Key Features

KPI Cards (Revenue, Profit, Growth %)

Monthly Trend Analysis

Interactive Filters & Slicers

Category Breakdown

Drill-through functionality
